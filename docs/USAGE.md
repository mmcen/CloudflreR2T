# 使用说明

## 快速上手

1. 启动程序，点击左侧底部「＋」添加帐号。
2. 填写帐号名称、选择登录模式并填入对应凭证（见下节）。
3. 点击「测试连接」确认无误后保存。
4. 选中该帐号，点击「连接」。
5. 在顶部选择存储桶，即可浏览 / 上传 / 下载对象。

## 帐号配置

### 模式一：R2 S3 API Token（推荐）

适用于拥有 S3 API Token 的用户，直连 R2，无临时凭证刷新开销。

- **Account ID**：Cloudflare 仪表盘 → R2 概览页右侧边栏，形如 `16 位十六进制`。
- **Access Key ID / Secret Access Key**：R2 → 管理 R2 API 令牌 → 创建 API 令牌，选择「对象读和写」权限，生成后复制（Secret 仅显示一次，请立即保存）。

S3 端点固定为 `https://<account_id>.r2.cloudflarestorage.com`。

### 模式二：R2 API Token

适用于希望用 API Token 统一管理多个资源的用户。

- 填写 **Account ID** 与 **API Token**（Cloudflare 仪表盘 → 我的个人资料 → API 令牌，或 R2 → 管理 R2 API 令牌，创建具备 R2 读写权限的令牌）。
- 程序会调用 Cloudflare v4 接口换取临时 S3 凭证，有效约 1 小时，到期前 5 分钟自动刷新，长任务无需手动干预。

### 模式三：Cloudflare 全局 API Key

- 填写 **Account ID**、注册 **邮箱** 与 **Global API Key**（仪表盘 → 我的个人资料 → API 令牌 → 全局 API Key）。
- 同样自动换取并刷新临时凭证。

### 模式四：自定义 S3 兼容端点

适用于 MinIO、AWS S3、阿里云 OSS 等任意 S3 服务。

- **端点地址**：如 `https://s3.ap-southeast-1.amazonaws.com` 或 `http://192.168.1.10:9000`。
- **Access Key / Secret Key**：对应服务的凭证。
- **区域（可选）**：部分服务要求指定，如 `ap-southeast-1`。
- **Path-Style 访问**：默认勾选，适合 R2、MinIO；使用 AWS S3 虚拟主机风格时取消勾选。

> 提示：自定义端点的「复制 URL / 临时链接」等功能同样适用。

## 代理加速

针对 R2 访问较慢的地区，可配置代理：

1. 左侧「设置」→ 代理设置 → 勾选「启用代理」。
2. 选择协议：HTTP / HTTPS / SOCKS5。
3. 填写服务器地址与端口（默认 `127.0.0.1:7890`，即常见 Clash 默认端口）。
4. 需要认证时填写用户名/密码。
5. 点击「测试代理连接」验证连通性后保存。

- 代理对所有 S3 请求与 Cloudflare API 请求生效。
- 修改代理后需重新「连接」帐号才生效（新增连接会立即使用新设置）。

## 系统托盘

- **关闭最小化到托盘**：点击窗口右上角 X 时，窗口隐藏到托盘而非退出（设置中可关闭）。
- **最小化时隐藏到托盘**：点击最小化按钮时同样隐藏（默认关闭）。
- **恢复窗口**：双击托盘图标、单击鼠标中键，或右键托盘菜单「打开 R2 Explorer」。
- **真正退出**：右键托盘图标 → 「退出」。
- 连接成功、隐藏到托盘等操作会弹出气泡通知。

## 文件管理

### 上传

- 点击右上角「上传」按钮，从菜单选择「上传文件」或「上传文件夹」。
- 或直接把本地文件 / 文件夹拖拽到右侧对象列表。
- 上传文件夹时保留相对目录结构，根目录为当前前缀下的文件夹名。

### 下载

- 单选文件：下载时弹出「保存为」对话框，可选择文件名与位置。
- 多选或文件夹：弹出「选择保存目录」，按对象 Key 的相对路径保存。
- 「打开」：下载到系统临时目录（`%TEMP%\R2Explorer\<桶名>\`）并用默认程序打开。

### 复制 / 剪切 / 粘贴

- 复制 / 剪切所选对象（支持文件夹，递归）。
- 进入目标目录后「粘贴」：复制模式保留原对象，剪切模式在复制完成后删除源对象（即移动）。
- 快捷键：`Ctrl+C` 复制、`Ctrl+X` 剪切、`Ctrl+V` 粘贴。

### 重命名 / 删除

- 重命名：单选对象，点击「重命名」或按 `F2`。文件夹重命名会递归重命名其下所有对象。
- 删除：`Delete` 键或点击「删除」。删除前默认弹出确认（设置中可关闭）。删除不可恢复。

### URL

- **复制 URL**：若帐号配置了「公开访问地址」（如 `https://pub-xxx.r2.dev` 或自定义域名），复制 `公开地址/桶/对象` 链接；未配置时自动回退为 1 小时临时链接。
- **生成临时链接**：为当前对象生成 GET 预签名链接，可选有效期 5 分钟～24 小时，适合分享给他人。

### 其他

- **新建文件夹**：创建一个以 `/` 结尾的空对象作为文件夹占位。
- **路径直达**：在路径框中输入前缀（如 `images/2026/`，`\` 与 `/` 均可用，可省略首尾斜杠）回车跳转；或点击右侧跳转按钮。
- **返回上级**：点击「返回上级」按钮。
- **筛选**：右上角搜索框按名称实时过滤当前目录。
- **刷新**：按钮或重新选择存储桶。
- **属性**：右键对象 →「属性」，查看大小、Content-Type、ETag、修改时间；文件夹显示对象数与总大小。

## 传输队列

- 底部队列实时显示每项任务的进度（上传 / 下载 / 复制 / 删除）。
- 每项任务可点击「✕」取消；「清除已完成」移除已完成/失败/已取消的任务。
- 「最大并发传输数」在设置中配置（1-32，默认 4），修改后重启生效。
- 提示：复制与删除任务按「对象个数」显示进度（如 `3 / 10`），上传下载按字节数显示。

## 快捷键一览

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl+C` | 复制选中对象 |
| `Ctrl+X` | 剪切选中对象 |
| `Ctrl+V` | 粘贴到当前目录 |
| `Delete` | 删除选中对象 |
| `F2` | 重命名选中对象 |
| `Enter` | 进入选中的文件夹（在对象列表获得焦点时） |

## 设置项

- **代理**：HTTP/HTTPS/SOCKS5、地址、端口、认证、连接测试。
- **窗口与托盘**：关闭最小化到托盘、最小化隐藏到托盘、启动自动连接上次帐号。
- **传输**：最大并发传输数。
- **界面**：主题（深色/浅色）、删除前确认。

设置保存在 `%APPDATA%\R2Explorer\settings.json`，删除该文件可恢复默认配置（不会影响云端数据）。

## 常见问题

### 连接失败怎么办？

依次排查：

1. **凭证是否正确**：Account ID 需为 R2 页面的 Account ID；Access Key / Secret / Token 需有 R2 读写权限。
2. **系统时间**：签名依赖 UTC 时间，偏差过大会导致 `RequestTimeTooSkewed`，请校准系统时间。
3. **网络与代理**：R2 域名在部分地区访问慢或不稳定，尝试在设置中配置代理并重新连接。
4. **临时凭证模式**：确认 API Token / Global Key 权限包含 R2；接口返回错误时错误信息会直接显示。

### 上传/下载任务失败

- 队列中失败任务会显示错误原因（悬停或查看任务状态）。
- 常见为网络中断、凭证过期（临时凭证模式会自动刷新）、本地磁盘空间不足、路径含非法字符。
- 单个任务可点击「✕」取消后重试。

### 「复制 URL」返回的是临时链接？

- 当帐号未配置「公开访问地址」时，自动使用 1 小时预签名链接。
- 在帐号编辑中填写公开域名（R2 公开访问或自定义域名）后重新连接，即可复制固定公开地址。

### 删除存储桶会清空数据吗？

- 会。程序会先递归列出桶内所有对象并删除，再删除桶本身。执行前有强确认提示，且不可恢复，请谨慎操作。

### 托盘图标不见了？

- 某些系统可能隐藏通知区域图标，点击任务栏托盘区的「显示隐藏的图标」箭头查找；仍不可见则重启程序。

### 修改并发数后未生效？

- 并发数在启动时读取，修改后需重启程序生效。

## 数据与隐私

- 帐号凭证以明文保存在本机 `%APPDATA%\R2Explorer\settings.json`，请妥善保管本机数据；不要在公共机器上保存高权限凭证。
- 程序仅与您配置的 S3 / Cloudflare API 通信，不包含任何遥测或统计上报。
